**What happened**

- `commons` went from **15 UI components to 24 installable artifacts across 7 layers** (ui · lib · script · config ·
  block · test · starter), all on the existing `shadcn add` mechanism. Published: 25 artifacts live on
  `raw.githubusercontent.com/thiengthb/commons`, verified through the GitHub API (the raw CDN caches ~5 min and lied
  for a while). All five repos pushed.
- **`starter-web-app` measured end to end** on a throwaway app: empty dir → `shadcn init --template next` (37s) →
  `shadcn add @thiengthb/starter-web-app` → build 5s → vitest + eslint green → `rebuild-and-verify.sh` → **healthy
  container + HTTP 200 in 44s**. Under three minutes, two commands.
- The acceptance run found **three shipping bugs no review had**: `@vitejs/plugin-react` made the starter
  uninstallable (Babel 8 vs the shadcn CLI's Babel 7 — npm refused outright); a registry item **cannot** merge a script
  into `package.json`, so shipped commands use `npx`; and `verify.env` became `verify.conf` because a name ending in
  `.env` is one gitignore rule from never being committed.
- Phase 0 caught two more, live: 11 of 15 committed artifacts carried **CRLF baked into the JSON string** (built on
  Windows), making the build non-reproducible and the CI gate impossible; and `data-table` had shipped **two commits**
  without its own bug fix because nobody re-ran the build.
- **`reuse-scan.mjs`** built — the counter behind the rule of three. Unit is a FILE, count is distinct PROJECTS.
  `jscpd` was tried first and rejected with evidence (0 clones for two files one comment apart). Threshold 0.72
  calibrated on this fleet's own known pairs. Two noise classes were only visible by running it: vendored shadcn
  primitives, and files `shadcn init` generates — reporting "extract `cn()` to commons" is the over-engineering the
  tool exists to prevent.
- **`reuse-guard.mjs` installed** (supervisor copied the file in, agent registered it in `settings.json`) — the
  per-write half: a new file matching a registry item is blocked once with the `shadcn add` command.
- The `todo` in-app emoji were replaced with lucide icons (11 sites, previewed and approved); Discord message copy
  kept its emoji behind a reasoned `rulebook-allow-file` directive, so `docs/gates.json` now has an **empty** allow list.
- The prettier config now has **one** installer: the `/coding-convention` templates were byte-identical to
  `config-prettier` and were removed; the skill keeps the settings table and points at the registry.
- **A parallel session moved the nine app repos into `projects/`** — and two tools from this pass degraded **silently**:
  `reuse-scan` found 0 of 22 groups, `audit-consumers` 87 of 97 files with 0 of 4 declared divergences. Both fixed by
  shape-based discovery, not a hardcoded folder name.
