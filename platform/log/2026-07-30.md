- The supervisor reframed the whole request: **stop pre-building patterns** for software that might never be written

  standing mechanism — when asked to build, the first thought is whether it already exists out there. They added the
  reason that matters: *"nhiều khi tầm nhìn tôi hạn hẹp không biết mình muốn gì"*, so an outside source exceeding the
  spec is to be **encouraged**, not treated as scope creep.
- Answered their two factual questions honestly. **Claude Code does NOT do this natively** — the tools exist but are
  discretionary, and the proof was in the session itself: they had to ask twice. On tools-vs-model: the published view
  agrees that verification is now the bottleneck, but it is **multiplicative**, not tool-instead-of-model.
- **The real finding was structural, and located precisely:** the platform already enforced ≥2 external prior-art URLs —
  via `plan-audit.mjs --hook`, which fires when a **plan file** is written. `/code-reuse`, the thing that fires before
  *coding*, had exactly two sources and both were internal. Rule present, enforcement present, behaviour absent.
- Wired the mechanism at three levels, all prose, deliberately no hook: `CLAUDE.md` §Code-reuse (ordered ①②③, code
  LAST, +254 tokens/turn), `/code-reuse` Step 1c (probe installed tools **before** web; web only at P2+), and a verdict
  log at `external-patterns.md §6` seeded with 7 rows (4 adopted, 3 refused). FOMO brake in all three — verified by
  counting, after claiming "all three" when it was only 2 of 3.
- The supervisor ran both proposal scripts themselves; **all 8 workflows now declare top-level `permissions`** and were
  committed+pushed across 8 repos. `commons` and `todo` CI both **green** — the two structurally distinct workflow
  shapes, verified for real rather than assumed. The other 6 are private and unreadable without `gh`/a token, and the
  recommendation was explicitly **not** to spend anything finding out.
- **A bug in my own CI poller led to the session's most transferable finding:** the shell here is **zsh, which does not
  word-split an unquoted `$var`** (it does split `$(...)`). `set -- $out` put the whole line in `$1`, so the poll ran all
  40 iterations. Chasing it found `rebuild-and-verify.sh` — shipped to every repo — sweeping `for route in $ROUTES`,
  which under zsh/dash collapses to one bogus route and can report **green having verified nothing**. Now asserts
