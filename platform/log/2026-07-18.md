**What happened** — one long interactive pass, many small requests, then one large extraction:

- **Settings/History/Resources UX.** Settings: JLPT + topics → checkboxes (topics 4-col), furigana
  checkbox→toggle, **VOICEVOX voice picker** (`voiceSpeaker` setting; `/api/tts?speaker=` already existed).
  History: 2-col grid, click→**detail modal** (was inline expand), rich **filter popover** (direction/
  result/type/level/length/topic/score-range/duration/date), audio moved to /resources.
- **Reusable UI.** New ui-kit assets: `breadcrumbs` (+ app `app-breadcrumbs.tsx`), `data-table`, plus
  `expanding-icon-button` / `filter-popover` / `search-input` (app-local). Removed redundant page
  **titles** (breadcrumb names the page); breadcrumb + tabs/save share one row; home breadcrumb toggled
  off then back on as the title.
- **VN timezone display** — pinned all shown timestamps to `Asia/Ho_Chi_Minh` (`lib/format.ts`
  `formatDateVN`/`formatDateTimeVN` + `formatDueExact`). Container already runs +07.
- **DataTable extraction (the big one).** Chose **TanStack Table** (user opted in) → generic config-
  driven `ui-kit/registry/thiengthb/data-table.tsx`; `items-table`+`vocab-table` became thin column-
  configs. Multi-sort (shift-click), **resizable columns** (exact px via a trailing **spacer column**),
  **drag column reorder** (native DnD, grip handle), show/hide, global search, pagination, self-contained
  sessionStorage+URL persistence.
- **Deploy trap fought + fixed** — after `npm install @tanstack/react-table` on Windows, the rebuilt
  container crashed: `better-sqlite3` "Could not locate the bindings file". Root cause = cross-OS lockfile
  → `npm ci` skipped the native build + Next `output: standalone` (nft) prunes the `.node`. Fixed in the
  Dockerfile (`npm rebuild better-sqlite3` + COPY the full module into standalone).
- **~10 rebuilds**, many atomic commits across 3 repos (sakubun, ui-kit, miniserver-platform), all
  pushed to `main`. Container healthy each time; verified by build/typecheck/98 vitest + curl of the live
  page (rows render, resize/grip/truncate present, 0 log errors).
