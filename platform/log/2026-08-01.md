## What happened — sakubun grew a terminal surface, and the one flow no gate could reach shipped broken

- **The ask (verbatim):** _"làm cho tôi tính năng màn hình giao diện terminal cho toàn bộ app sakubun … thay vì
  thao tác giao diện bằng web, thì bây giờ tôi có thể thao tác bằng cli"_, then a follow-up: _"có cách nào bạn
  deploy local tự động bằng docker như phần web không"_.
- **Three scope forks were put to the user BEFORE building**, with a flagged recommendation each; all three
  accepted: both front ends (TUI + single commands) · a new `/api/cli` endpoint on the EXISTING per-user
  `McpKey` bearer · the tutor loop (generation/grading) deliberately left with Claude for v1.
- **Shipped:** `lib/cli/` (42 commands / 9 groups declared as DATA, the `lib/mcp/catalog.ts` idiom),
  `app/api/cli/route.ts` (GET catalog / POST dispatch), `cli/` (plain `.mjs`, no build step — command mode on
  `node:util parseArgs` + a full-screen **Ink** TUI whose sidebar mirrors the web nav), and `/guide` narration
  plus a reference table rendered from `cliCatalog()`. Gates ended at **56 files / 680 tests**, lint/tsc/build clean.
- **Then packaged into Docker on request:** the client ships INSIDE the app image (`cli-deps` stage + a
  `/usr/local/bin/sakubun` shim), the login in a named volume so a rebuild does not log you out, and a one-line
  launcher per shell in `bin/`. The category difference was stated rather than papered over: the web half is a
  SERVER Docker keeps alive; a CLI is a client that runs and exits, so "deploy" can only mean removing the setup.
- **Two defects reached beyond the tests, and both were found by RUNNING the artefact:**
  `npm install --omit=dev <pkg>` pruned the two packages it was explicitly asked for (they are devDependencies in
  the manifest that was in scope), so the first image was 482 packages with neither in it → `known-traps.md` §17;
  and `sakubun login` died on its first prompt (`node:readline`'s `rl.question` is a callback returning
  `undefined`) — reported by the user, not by any gate.
- **Cleanups that were not the feature:** `npm run format` rewrote the whole repo (CRLF tree vs `endOfLine: lf`)
  and had to be unpicked file by file, keeping only this session's edits and reverting 4 reformats of files it
  never authored; a stray MCP-lab dev server + its DB were killed by hand after `mcp:lab:down` failed on Windows.
