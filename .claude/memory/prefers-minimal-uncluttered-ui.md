The user repeatedly asks to REMOVE UI clutter and keep only what's essential. Examples (2026-07-24,
sakubun): strip the streak celebration to just the flame + day count (drop the milestone banner + the
caption); hide a table's search/filter/action toolbar entirely when there's no data (not a live toolbar
over an empty grid); drop a redundant brand-mark icon when the logo is already in the nav. His phrasing:
"chỉ có như vậy" (just that), "bớt đi" (cut it down).

**Why:** He judges an interface by signal-to-noise — decorative or redundant elements read as clutter,
not richness. This is the visual-design face of [[practice-first-lean-ceremony]] (over-engineering is
the enemy) and [[capability-over-rearrangement]] (keep what the user DOES; cut ornament).

**How to apply:** Default to the leaner option and question every secondary banner / caption / toolbar /
icon — does it earn its space? Propose the minimal version first. When he says "bớt đi" / "chỉ để …",
take it literally: remove the element, don't merely shrink it. Pair with his completeness instinct
([[apply-features-across-all-surfaces]]) — minimal BUT applied consistently across every surface.
